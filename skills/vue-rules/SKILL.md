# Vue rules (bundled)

Five upstream ECC `rules/vue/*` files back the `vue-reviewer` checklist:

- `references/coding-style.md` — conventions and naming for Vue code
- `references/hooks.md` — composable/reactive rules
- `references/patterns.md` — component and state patterns
- `references/security.md` — Vue-specific security rules
- `references/testing.md` — Vue testing expectations

Read the relevant reference file when a review needs more detail than the
reviewer's inline checklist; they are upstream-verbatim (source stamps in each
file).
