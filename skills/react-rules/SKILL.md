# React rules (bundled)

Five upstream ECC `rules/react/*` files back the `react-reviewer` checklist:

- `references/coding-style.md` — conventions and naming for React code
- `references/hooks.md` — hook rules and dependency correctness
- `references/patterns.md` — component and state patterns
- `references/security.md` — React-specific security rules
- `references/testing.md` — React testing expectations

Read the relevant reference file when a review needs more detail than the
reviewer's inline checklist; they are upstream-verbatim (source stamps in each
file).
